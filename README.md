# 终焉之地 · beiklive助手

Balatro（小丑牌）非官方同人模组：以《十日终焉》为题材的大型内容扩展 + 一个独立的 **「终焉之地」挑战模式**。

| 项 | 值 |
|---|---|
| 模组 ID | `beiklive_helper`（前缀 `blh`） |
| 版本 | v2.3.2 |
| 依赖 | [Steamodded (SMODS)](https://github.com/Steamodded/smods) |
| 实测环境 | Balatro 1.0.1o-FULL · Steamodded 26.829.0 · Lovely 0.9.0（iOS） |
| 语言 | 简体中文 / English |
| 素材 | **全部程序化生成**，仓库内不含任何原版游戏素材 |

---

## 安装

1. 先安装 Steamodded（SMODS）。
2. 把 `beiklive_helper` 整个文件夹放进 Balatro 的 `Mods` 目录：
   - Windows：`%AppData%/Balatro/Mods/`
   - macOS：`~/Library/Application Support/Balatro/Mods/`
   - iOS：放进你当前 Steamodded 安装所使用的 `Mods` 目录（本模组在 iOS 实测，路径随安装方式而异）
3. 启动游戏，主菜单 `Mods` 里应出现 **beiklive助手 v2.3.2**。
4. 主菜单 `挑战` → **终焉之地**（Ten Day Ultimatum）进入主题模式。

配置页：主菜单 `Mods` → `beiklive助手`（起始金钱 / 每回合出牌次数 / 每回合弃牌次数 三个滑条 + 一键解锁全部内容）。

## 已实现的内容

### 1. 挑战模式「终焉之地」

- **10 天**一局：开局把 `G.GAME.win_ante` 置为 10（原版默认 8），第 10 天击败**天龙**为真结局。
- 起始条件：标准牌组 + 随机 1 张回响小丑 + $4 + 0 道；出牌 4 / 弃牌 3。
- **独立货币「道」+ 独立 HUD 计数器**：金钱仍只用于商店，道只用于本模式的赌命。
- **完全隔离原版内容**（该模式下原版内容一律不可获得）：
  小丑 / 塔罗 / 幻灵 / 星球 / 优惠券 / 标签 / 版本 / 封印 / 贴纸 / Boss 盲注 / 卡包。
  退出模式或开普通局时自动还原原版池。
  实现方式：`Game:start_run` 前后**原地重建中央池**（含稀有度池与 `ObjectTypes.Joker.rarity_pools`）+ 把原版 key 写进 `G.GAME.banned_keys` + 关停商店的星球/扑克/卡包入口。
- **12 个生肖 Boss 盲注**取代全部原版 Boss，按底注分段出场，第 10 天是 showdown 的**天龙**。
- 牌型（PokerHand）与牌组（Back）保持原版，不做增补。

### 2. 道 · 经济系统

| 项 | 数值 |
|---|---|
| 小盲注 | `10 + 5 × 天` |
| 大盲注 | `20 + 8 × 天` |
| Boss | 人级 80 / 地级 130 / 天级 200 / 天龙 400 |
| 十天基础总量 | **2575 道** |
| 性能奖励 | 剩余出牌 ×4；剩余弃牌 ×3；超额分数比率 ≥1.5 / ≥3 / ≥6 → +10% / +25% / **+40%（封顶）** |
| 赌命（Boss 失败免死） | 第一次 500 道 / 第二次 800 道 / 之后 1200 道（价格递增） |
| 免死充能 | 标签「玄武·公正」给 1 次免费免死 |
| 提前结局 | 道 ≥ **3600** → 天龙提前降临 |
| 反刷 | 天龙需求分数 ×(1 + ⌊道/500⌋ × 0.1)，进入天龙战时结算一次；道结算幂等；道只由战斗产出 |

## 美术素材：现状与不足

**现状**：8 张图集全部由 `dev/gen_art.py` 程序化绘制（纯 Python 标准库 + 自写 PNG 编码器与超采样画布，不依赖 PIL）。
形制对齐原版资源尺寸：小丑/塔罗/优惠券/幻灵 71×95 整卡、盲注筹码 34×34、标签 34×34、封印 71×95 徽章位，并同时输出 `1x` / `2x`。

**不足（如实说明）**：

1. **没有手绘/外包美术**。全部是几何构图：6 种构图模板 × 36 个母题 × 8 种底纹 × 15 个符号，靠配色与母题区分。
   → 结果是**同一稀有度、同一批母题之间的辨识度有限**，风格是"抽象几何 + 配色"，不是原版那种精细插画。
2. **没有分层源文件**（无 PSD / ASE / ASEprite）。要精修只能改生成脚本参数或直接覆盖 PNG，缺少可交给美术的加工层。
3. **盲注只有单帧**。原版 Boss 盲注是多帧循环动画，本模组的盲注立绘是静止的。
4. **卡面烘焙的英文不做本地化**：竖排 `JOKER`、塔罗名牌、`VOUCHER` 匾额等是直接画在贴图上的英文（这点与原版一致——原版贴图也带英文），但中文语言下观感上仍是英文烘焙字。
5. **没有周边素材**：道 HUD 是纯文字（没有自制图标），卡背 / 牌库 / 商店图标 / 盲注说明插画等全部沿用原版。
6. **只有 1x / 2x 两档**，没有更高分辨率版本，也没有做原版那种针对不同屏幕的细节微调。

> 本仓库**不包含任何原版游戏素材**。开发时仅把原版资源的尺寸与形制当作排版参考，成品 PNG 全部是重新绘制的。

## 声音素材：现状与不足

**现状**：模组内**没有任何音频文件**（无 `.ogg` / `.wav` / `.mp3`），所有事件都调用原版音效（如 `play_sound('coin2')`）。

**不足（如实说明）**：

1. **零新增音效**。因此「道结算」「赌命」「天龙降临」「一键解锁」等关键节点**没有专属音效**，听感上与原版结算几乎没有区别。
2. **没有 BGM / 环境音**。主题模式没有专门的音乐或氛围铺垫。
3. **没有配音**。原著角色的台词/提示只用文字 `attention_text` 呈现，没有语音。
4. **没有音频选项**（音量、音效开关、静音）——沿用游戏全局设置。

计划（未实现）：至少为「道结算 / 赌命 / 天龙降临」补 3 个短音效，并让盲注切换带专用提示音。

## 已知限制

- 只在 **iOS + Steamodded 26.829.0** 实测；其他平台与版本未验证。
- `dev/test_blh.lua` 的 249 项测试是**替身桩（stub）**：它覆盖注册数量、图集坐标、经济公式、边界条件、文档合规与本地化文案，但**不覆盖引擎渲染与真实 UI 布局**；真机仍需按 `DESIGN.md` §14 / §22.6 / §23.5 的手工清单验收。
- 平衡性按"10 天预算"推算校准，未做大样本对局统计。
- 与其它模组的兼容性未逐一验证（已知与 CardSleeves 共存时挑战描述页正常）。
